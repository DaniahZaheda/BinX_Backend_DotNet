## How to Run the Projects

1. Clone the repository:

```bash
git https://github.com/DaniahZaheda/BinX_Backend_DotNet.git
```

2. Open the required project folder:

```bash
cd BinXTech-Backend-DotNet-Internship/Week1/Day1/ProjectName
```

3. Run the project:

```bash
dotnet run
```
