# Sprint 1 Planning

## Project

Task & Project Management API

## Sprint Goal

Build the complete database schema, apply EF Core migrations,
and implement the core project and task management routes.

## Sprint Duration

1 Week

## Sprint Scope

The sprint focuses on:

- Complete database schema design
- EF Core configuration
- Database migrations
- Project management core routes
- Task management core routes
- Basic API functionality

## Definition of Done

A task is considered done when:

- The implementation is complete.
- The code builds successfully.
- The database changes are applied.
- The endpoint works correctly.
- The implementation follows the project structure.
- The task is tested manually when applicable.
