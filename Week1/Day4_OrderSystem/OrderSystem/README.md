# Day 4 – LINQ

## Objective

Learn how to query and manipulate collections using LINQ.

## Completed

* Filtered and searched data.
* Sorted collections.
* Used common LINQ methods such as `Where()`, `Select()`, `OrderBy()`, and `FirstOrDefault()`.
* Applied LINQ to the Order Management System.

## Outcome

Learned how LINQ simplifies working with collections and improves code readability.
